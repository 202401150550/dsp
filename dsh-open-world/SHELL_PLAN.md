## 1. 目标用户与成功标准

| 谁 | 要什么 |
|----|--------|
| 本机重度 DSH 用户 | 少切窗口，一眼看稳不稳、能点什么、刚发生什么 |
| 你要「传出去」的接收方 | 5 分钟会用，不需懂 Bridge/Host/ATI 术语 |

**30 秒验收（对外口径）**

1. 打开 ✦ → 左栏 **状态** 看到健康与通路  
2. **动作** 或点中间节点 → 能打开任务/回退等真实能力  
3. **事件** → 看到最近日志或消息  

做不到这三步的功能，不进默认主路径。

## 2. 分层（冻结）

```
L3 叙事（可选、默认识别为壁纸）  ATI 实验室预设、深空背景
L2 壳 + 系统调用（产品核心）     左三栏 · 主视图节点 · OWIP · 信箱
L1 宿主（只桥接）               DSH Harness / 各插件 API
```

**禁区**：重做聊天 UI；无限加 `/action`；把隐喻当真实 ML；默认路径依赖 Hindsight daemon / 第二屏。

## 4. 接口契约（目标态）

| 通道 | 给谁 | 规则 |
|------|------|------|
| 同源 cookie | Desktop 壳内 | 默认 |
| Space Bearer | 第二屏 / LAN | 只读观察；高级 |
| 进程外裸 HTTP | 脚本 | **不承诺**（Desktop 常 403）；联调走 CDP |

**Host 核心动作（日常推荐，文档置顶）**  
`send-message` · `idea-inject` · `world-state-*` · `space-token-*` · `memory-search`  

其余（RRM 试用、idea-compare、pair、notification…）标 **高级**，可不进首屏。

**Snapshot**  
- UI 主路径：`GET /api/open-world/snapshot?view=shell`（瘦身）  
- 完整 snapshot：无 `view` 或非 shell，留给 Monitor / 调试  
- 主路径字段：`core` · `nodes[].action` · `events` · `mailbox` 摘要 · `fleet` 摘要；ATI lab 仍随壳走主视图
