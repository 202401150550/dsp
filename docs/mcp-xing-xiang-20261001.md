## 0. 这一轮解决什么

上一轮交付了园子（第一个"象"）。主人指出了更深一层：

- "世界是由无数个为什么组成的" —— 世界要能被追问

## 1. 学理：三条学习结论（学完之后的转述）

### 1.1 虚妄 ≠ 不存在（最容易读错的四个字）

《金刚经》"凡所有相皆是虚妄"的"虚妄"，历代注疏一致的读法是 **"非真实永恒"（无自性、条件依存的临时假合）**，不是"不存在"。
所以佛法**明令禁止**因此走向顽空（"于法不说断灭相"）；《维摩诘经》给的日用口诀是
**"不坏假名而演实相"** —— 不破坏象，而演出性。

**对软件的直译**：UI 象是"临时假合"（它不是系统本身，随时可换），但**不许删掉 UI 走纯 JSON**（顽空）；正确姿势是"不坏象而演性"——象照常好看，性随时可穿。

### 1.2 大象无形，有无相用

《道德经》："大象无形"（最大的象没有固定形状）；"有之以为利，无之以为用"（房子真正在用的是"空"的部分）。
**直译**：最重要的那个"象"是**无形的**——就是数据契约本身。象层所有的形状，都是从这个无形之物投影出来的。

### 1.3 道通为一，象无高下（齐物论）

《庄子》齐物论："举莛与楹，厉与西施，恢诡谲怪，道通为一"——小草与大柱、美与丑，在道上没有分别；分别心一起，人就迷失在万物里。
**直译**：园子、五行轮、阶梯、番茄藤、拓扑图——**没有哪个更"正"，都是同一份性的投影**。上一轮我说"园子是正解"，这本身就是一种执着。这轮纠正：园子只是象之一。

### 1.4 五行的本质：不是五种物质，是带反馈的系统论

五行是**五种运行状态**：木曰曲直（生发舒展）、火曰炎上（升腾显明）、土曰稼穑（承载化育）、金曰从革（收敛变革）、水曰润下（流动收藏）。
其核心是**生克双环**：相生是促进链（正反馈），相克是制约链（负反馈）；无生则死寂，无克则失控。
学界通称五行是"原始的系统论"。**直译**：五行可以用来做系统的**动力学诊断语言**——而且是诚实的那种（每条边背后是真实数据关系，source=derived，公式可单测）。

## 2. 架构：性 / 相 / 执 / 见 四层定稿

| 佛学 | 软件实体 | 规则 |
|------|----------|------|
| **性**（空、缘起、无形） | **基准 = snapshot schema + action 契约 + source 制度**（OWIP 已有） | 固定不变；自己不显示任何东西；一切象由它缘起 |
| **相**（假名、临时假合） | **象 = 每一种画法**（园子/五行轮/阶梯/番茄藤/拓扑图/列表……） | 无高下（齐物）；可增可换可弃；必须带"喻"标 |
| **执**（把相当真） | **把某一种画法当成系统本身** | 病。上一轮的"园子唯一正解"、旧版的"拓扑图唯一正解"都是执 |
| **见**（见诸相非相） | **随时看穿任一象、直接见性** | 药。每个象必须内置"见性"能力：字段浮出 + 换象 + 追问为什么 |

三条铁律（写进任何象的实现要求）：
1. **换象不失**：切象时数据零变化、动作集合不变（园里能"记一件事"，番茄藤里也能）——若见诸相非相的交互定义。
2. **不坏假名**：不许删象走极端（顽空）；每个象都要好看、都要带"喻"标。
3. **缘起可问**：世界由"为什么"组成——任何元素、任何生克边，一问即答：白话缘起（因 → 果 → 数据出处）。


## 4. 五行动力学模型（系统诊断语言 v1，全部对应真实数据关系）

**五行归位**（取象比类，按"运行状态"归，不按物质归）：

| 行 | 状态 | 系统相位 | snapshot 字段 |
|----|------|----------|---------------|
| 木 | 曲直·生发 | 会话（话头萌发） | sessions |
| 火 | 炎上·升腾 | 任务（在做的事） | taskBoard.doing |
| 土 | 稼穑·化育 | 记忆（经历化土） | memory |
| 金 | 从革·收敛 | 回退（修剪恢复） | rewind + 审计 |
| 水 | 润下·流通 | 连接（活水下达） | space |

**相生**（促进链，正反馈）：
- 木生火：会话里的话，长成任务（message → task 创建）
- 火生土：任务做完，化入记忆（task done → memory 入库）
- 土生金：记忆攒厚，才敢回退（有据可依的 rewind）
- 金生水：修剪与审计，让连接可信（回退记录 → 跨机信任）
- 水生木：外来见闻，激起新话头（peer 见闻 → 新会话）

**相克**（制约链，负反馈）：
- 金克木：回退修剪会话（rewind 终止旧会话态）
- 木克土：新话压旧忆（高 intake 覆盖旧记忆权重）
- 土克水：记忆未密封，连接不发（outbox seal 门控 space 同步）
- 水克火：连接限流任务（外部写入占用任务通道则降速）
- 火克金：任务正忙，锁住回退（busy → rewind 暂不可用）

**衡**（诊断，source=derived，白话输出）：
- 火旺土薄：doing 多而 todayIn 少 → "今天做得多、记下的少，要不要把结果落进湖里？"
- 水涸：peers=0 且久未同步 → "活水断了，桥那头很久没人来。"
- 金钝：points 过旧 → "剪刀钝了：存档太久没打，回去的路有点远。"
- 判定式全部可单测（符合 WORLD_PLAN L0"真公式可证伪"）。
