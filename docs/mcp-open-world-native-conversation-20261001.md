# Open World：原生问答闭环验收

2026-10-01 · v2.78 · 构建 `0e3c928900`

## 已完成

- **世界内提问、世界内接收真实回复**：新建或明确选择原生 Session；不再隐式投递到桌面当前会话。
- **上下文追问与持久化**：首次记住测试口令，后续不提供口令也能回答；正常重启 Desktop 后仍能打开原对话并继续追问。
- **明确的状态与停止操作**：提交不等于回复完成；根据原生回合结束事件确认结果。停止只针对当前选定会话，排队问题不会被偷偷删除。
- **安全处理不确定发送**：响应丢失时先读取记录核对，不自动重发。解除发送锁定需二次确认，并提示重复风险；解除本身不会发送问题。
- **历史刷新补齐**：重新打开或刷新历史时获取最新记录位置，不再使用侧栏缓存的旧序号而漏掉新回复。
- **入口简化**：移除“注入会话”和“转到桌面会话”，增加“原生问答”入口；本地记录仍明确不自动产生助手回复。

入口：开放世界 → 事件 → 在聊天坞继续 → **原生问答** → 新建问答／选择会话后“继续此会话”。

## 实测发现与处理

1. 初版依赖原生接口的请求 ID 去重，但运行中实测仍发生重复排队，**仅影响第一个隔离验收会话**。没有删除这份失败证据；改为不对不确定请求自动重发，第二个隔离会话验证没有重复问题。
2. 浮窗输入区曾被裁切，已修复并复测。
3. 启动脚本曾误选 C 盘旧版 Desktop，进入配置不兼容恢复页。正常关闭后改用原先验证过的 D 盘安装；未修改配置格式、迁移数据或强杀进程。启动器现在不再把恢复页／空白页判作就绪。
4. 注入网络、读取、明确拒绝和浏览器存储故障验证提示与恢复；这些是受控故障模拟，不冒充真实服务商故障。

## 边界与仍待处理项

- 原生问答当前支持文字；回复通过轮询原生记录回流，不是逐 token 流式输出。模型仍可按用户请求使用其原有工具权限。
- 对话历史由原生 Session 保存。仅待确认发送信息使用浏览器 sessionStorage；不声称未发送草稿或待确认状态可跨 Desktop 重启完整恢复。
- HTML 继续使用静态隔离预览；不声称脚本、外部资源或其中导出按钮可运行。Office/PDF 等格式仍以下载后打开为主。
- **真正的回退／文件恢复兼容尚未完成**。已定位到旧回退插件仍依赖 `chat.order`，没有用真实用户历史试做回退，也没有执行恢复操作。
- **侧栏旧全量回归的 14 个失败与 1 个未捕获异常仍待处理**；本轮 715/0 是 Open World 套件，不代表整个侧栏仓库全绿。
- 外部失效 URL、更多文档格式及完整窄屏／无障碍矩阵未全部验收。

后续顺序保持：回退兼容与安全隔离验收 → 侧栏剩余回归失败 → 具体失效入口。任务插件继续保持禁用。
