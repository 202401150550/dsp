# 完成前自证纪律（Self-Verify Discipline · v1）

> 渊源：Tianshu CVM「拦截未验证报完成」（72 hooks/5 阶段）的同源思想。我们不建 hook 运行时（那是 harness 层），把纪律落在工作流制度上——借意不借码。

## 三条铁律

1. **报完成必附证据**：说「完成」时必须同句给出——跑了什么命令 + 看到什么结果（exit 码/断言数/日志路径）。无证据的「完成」= 未完成。
2. **修一守一**：每修一个 bug，同步加一条防回退断言（census/garden-view 套件），让同类问题永远跑不过第二次。
3. **改动留痕**：远端文件改动后必须回读对账（md5/行数/关键行），防漂移与旧镜像回退（两次事故换来的规矩）。

## 自证清单（交付前 30 秒过一遍）

- [ ] 全量测试绿？证据日志路径？
- [ ] 本次改动各有一条防回退断言？
- [ ] 远端与本地镜像 md5 一致？
- [ ] 文档同步（docs/mcp-*.md 或账本）？
- [ ] 未 commit 事项已向用户声明？
