## 修订（2026-10-02 · 用户定调：功能按需，意象克制）

用户新增两问：「和别人不一样吗？能做得更好吗？」——写进甄别标准。**门槛三问**（以后任何候选过堂）：
①别人有吗？有→默认不做；真需要→走生态安装不自己造。②扎在我们独有资产上吗（记忆/园子/用户掌控）？不扎→撤，意象层尤其从严。③更好拿什么证明？拿证据（使用数据/断言/真机验收），不拿感觉。

**处置修订**：
- #10 北斗指路：**撤回**。星辰意象 Tianshu 已占，跟随无差异。
- #6 书房意象：**降级**。只按需装 @huiliyi37/dsh-office（纯功能件），入口从简（聊天坞一个「生成文档」动作），不做新景；出现真实使用证据后再议是否给景。
- #5 registry tools 粒度：保留。纯后端工程，前端零改动。
- 待批 A3 语义同步更正：「装 office 插件 + 聊天坞动作」≠「书房新景」。

**差异化宣言**：功能清单必然趋同，不构成不一样。我们唯一不可复制的资产是「园子=用户自己的世界」——记忆湖是用户的记忆、信箱是用户的往来、47 条指令一花一草一木可操控。同类产品是替用户干活的员工，园子是用户的地方。后续一切候选必须扎在这条资产上，否则不进待办。
