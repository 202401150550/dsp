# 550C「播完才进门」修复与优化路线（2026-10-01）
## 主诉与内核诊断
主诉：点「进世界」总感觉没播完就被切走。内核（src/client.js + show.js）逐段核验结论：
- show 本身**真演完**：简易档结尾 600ms 定格拍；完整档结尾 T-4 倒计时（4×160ms）+ 900ms 收束拍；start() 注释即「resolves when it has played out」。
- 看门狗（简易 12s / 完整 30s）不会掐健康播放。
- **病根**：finish() 在淡出**开始**瞬间 resolve（开门），世界立即入场——片头最后 520ms 淡出（FADE_MS=520）与入场浪潮（1100ms）赛跑，观感即「没播完」。
- **帮凶**：点击/Esc 无最短播放保护，「进世界」双击误触即秒跳过。
## 本轮修复（_scratch/dsh-550c-boot/src/client.js，node_modules 为链接、直装）
1. **开门挪到 dispose()**（淡出彻底结束、覆层移除时）：世界等片头完整收场再进；所有退出路径（播完/跳过/异常/看门狗）funnel finish→fade→dispose，仍不会悬挂。
2. **650ms 最短播放保护**：开演 650ms 内忽略点击/Esc，防误触秒跳。
3. playSplash 注释同步更新。语法 node --check=0；scripts/verify.mjs 需 --url 连真机，留待重启后跑。
## 是否需要添加内容
**不加剧情**。简易/完整两档的收束拍都在，缺的不是内容是时序；再堆内容反而加重「急」。后续可加的只有两样轻的（见路线）。
## 优化路线（具体到方面）
1. **跳过可见性**：片头角落加一行「点击 / Esc 跳过」（现仅在设置页文案里说，片头本身没提示）——低优先，涉 markup。
2. **节奏数据化**：实测记录 simple/full 两档总时长与各段占比，写成 README 数字（「简易 ≤N 秒」），防止未来改动画时无基准。
3. **prefers-reduced-motion**：系统开启减弱动态时直接跳动画秒进——小白机/低性能机友好。
4. **性能审计**：show.js 的 setInterval 族（fps/clock/代码行）在 skip 路径的清理已由 cancel+enhance() 覆盖，可加一处断言测试兜底。
5. **色彩同源强化**：结尾定格拍让 logo 琥珀辉光呼吸一拍（片头色 = 世界色 #E7B24B 同源），把「从片头落进世界」的色彩连续性做实。
## 特点定位（与其他内容对比）
- **550C 片头**：琥珀 CRT 终端仪式感——「进门钥匙」，机器在开机自检的戏剧化表演；对比对象是 DSH 壳的现代扁平 UI。
- **开放世界·园**：水墨科技中国风、印章红、竖排信纸——「散步庭院」；对比对象是片头的硬核终端感。
- **同源点**：琥珀 #E7B24B 贯穿片头 logo、世界 accent、抵达浪潮、品牌小行星——一条色彩血脉，让「进门」不换台。
- 分工：片头管「仪式与身份」（我到哪了），园子管「生活与对话」（我在干什么）；两者经「进世界门」衔接，本轮让这扇门在正确的时刻打开。
## 验收（重启 DSH Desktop 后）
点「进世界」：片头完整播完（含结尾定格）→ 淡出彻底结束 → 世界才入场；连点两下不会秒跳过；Esc 在开演 650ms 后仍可跳。
