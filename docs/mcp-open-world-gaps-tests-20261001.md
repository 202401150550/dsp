## 本轮实际测试

### 世界内文件格式

在既有独立验收会话的工作区放入有效的 `.docx`、`.xlsx`、`.pdf` 文件，通过世界内“历史与文件 → 查看工作区文件”逐个打开。

**12/12 通过**：三种格式均明确提示不支持内嵌预览，不显示乱码或伪预览，下载入口文件名正确，下载链接返回的字节 SHA-256 与原测试文件一致。

这里验证的是下载链接和完整字节，**没有自动操作系统保存对话框，也没有实现 Office/PDF 渲染**。PPTX 未在本轮实机测试。

同期世界入口复验 **21/21**，原生问答重开复验 **3/3**。

### 真实终端

发现并新增测试覆盖：
1. 已退出的终端在清理时仍重复调用 native kill。
2. Windows 终止信号已提交，但 onExit 尚未到达时，后续信号／清理再次终止同一 handle。

新增测试修复前 **2 失败、1 通过**；调整退出检查和 Windows 终止提交去重后，相关非原生专项合计 **30/30 通过**，TypeScript 检查通过。

但真实测试结果仍不稳定：

| 运行 | 结果 |
|---|---|
| 修复前真实 PTY 单独运行 | 20/20，仍有 AttachConsole 日志 |
| 修复后真实 PTY 单独运行 | 20/20，仍有 AttachConsole 日志 |
| 修复后与其他专项组合运行 | 50 项计划中 43 项通过；1 个 worker 异常退出，未完成全组 |

**重复终止问题有独立测试证明，但并未解决底层 worker 异常。不能用单独运行通过替代组合失败。**

本轮终端修改仅保留在工作分支中，未编译上线、未重启部署。已部署的 Open World 仍为上一轮 `v2.78 / 0abe5e9b55`。没有启用任务或执行真实回退。
