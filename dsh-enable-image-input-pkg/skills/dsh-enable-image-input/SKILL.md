# 修复 DSH 图片输入

## 原则

- 先确认目标模型或网关确实支持图片输入，再修改 Harness 的能力声明。套餐支持视觉不等于当前模型 ID 必然支持视觉。
- 只修改 `llm-pi-ai` 中目标提供商、目标模型的 `input` 字段，不改 API 地址、密钥、模型 ID 或其他提供商。
- 优先调用 DSH 自带的设置接口，使配置经过模式校验并实时生效；不要直接猜测或覆盖整个设置文件。
- 不把用户图片发送给外部模型做自动验证。完成本地验证后，让用户用不敏感的测试图片自行发送。
- 修改前生成回滚文件；不要在输出中打印密钥或凭据文件内容。

## 工作流

下列命令中的 `<技能目录>` 是本 `SKILL.md` 所在目录。执行捆绑脚本时使用其绝对路径，不要假设当前工作目录就是技能目录。

### 1. 定位问题

确认现象是添加图片后发送时提示“当前模型不支持图片，请切换支持图片的模型”，并记录界面当前选中的模型。

确认 DSH 网站正在运行。默认地址是 `http://127.0.0.1:3080`；若端口不同，先从启动日志或监听端口中确定地址，再传给脚本的 `--server`。

确认目标模型确实支持视觉：优先查套餐控制台、模型说明或官方文档。若无法确认，停止修改并请用户确认模型能力。

### 2. 只读诊断

先列出由 `llm-pi-ai` 管理的已配置模型：

```bash
node "<技能目录>/scripts/dsh-image-input.mjs" --list
```

结合 DSH 界面当前模型，记录对应的提供商和模型 ID，然后明确指定：

```bash
node "<技能目录>/scripts/dsh-image-input.mjs" --provider openai --model ark-code-latest
```

必须同时提供 `--provider` 和 `--model`。不要让脚本猜测当前会话模型，以免修改其他模型。

`--list` 和带模型参数但不含 `--apply` 的命令都只读；不带操作参数的空命令不会猜测模型。

非默认地址：

```bash
node "<技能目录>/scripts/dsh-image-input.mjs" --server http://127.0.0.1:3080 --provider openai --model ark-code-latest
```

若脚本报告该模型不属于 `llm-pi-ai`、提供商不存在或模型没有配置条目，不要强行新增配置；先检查用户是否选错提供商，或该模型是否由另一个适配器管理。

若在受限沙箱中连接本机地址时出现 `EPERM`，以只允许访问 DSH 回环地址的最小权限重跑同一条命令，不要把该错误误判成网站未启动。

### 3. 应用修复

在用户已确认模型支持视觉后运行：

```bash
node "<技能目录>/scripts/dsh-image-input.mjs" --provider openai --model ark-code-latest --apply
```

脚本会：

1. 读取 `llm-pi-ai` 当前设置及修订号。
2. 保留模型条目已有字段，只把输入能力补为 `text` 和 `image`。
3. 在当前目录生成不含密钥的 JSON 回滚文件。
4. 通过 `settings.mutate` 写入并再次读取设置验证结果。

若提示配置已经包含图片输入，不要重复写入。

### 4. 验证

再次运行只读诊断，应看到 `图片输入：已启用`。

确认 DSH 首页返回正常状态，然后刷新页面。让用户重新添加一张不敏感的测试图片并发送。若仍出现相同的本地提示，确认页面连接的是刚刚修改的同一个 DSH 实例。

若本地提示消失但方舟返回模型错误，说明 Harness 的本地拦截已经解除，继续检查当前 Coding Plan 实际路由到的模型是否支持视觉、模型 ID、套餐权限和网关兼容性；不要反复修改 `input`。

### 5. 回滚

使用应用修复时打印的回滚文件：

```bash
node "<技能目录>/scripts/dsh-image-input.mjs" --rollback ./dsh-image-input-backup-时间戳.json
```

回滚后重新运行只读诊断确认。

## 安全边界

- 不读取或输出 `~/.dsh/.credentials.yaml`、环境变量中的 API Key 或请求头。
- 不替换完整的 `~/.dsh/settings.yaml`。
- 不把某个套餐的视觉能力硬编码为所有模型都支持图片。
- 不自动发送用户截图、照片或文档到外部模型。
- 不需要公网图片 URL；DSH 会把浏览器图片保存为附件并转换为模型请求。只有目标 API 明确要求公网 URL 时，才按用户环境规定使用对象存储。
